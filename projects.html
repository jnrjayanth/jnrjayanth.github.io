Almond Jug · October 2026

What does an answer cost in water?

Personal project · one week · solo

Open the live app View the source

Every LLM response consumes water — for datacenter cooling and for the electricity behind it. The figure is real but abstract, so Almond Jug makes it physical: you chat normally, and a procedurally generated gallon jug fills in real time as you go.

The unit is the point. A millilitre figure means nothing to most people; a gallon jug visibly filling does, and the almond reference gives a second anchor — California almonds are the canonical example of a crop whose per-unit water cost surprises people. Put the two side by side and the scale of LLM inference stops being a statistic.

Built and deployed in a week with Next.js, TypeScript, and React Three Fiber on Vercel, with Mistral serving the chat.

01

Real usage, not an estimate of an estimate

A serverless route handler proxies the streaming completion and pulls per-request token counts out of the response stream, so the meter reflects what the request actually consumed rather than a guess from character count.

02

Ranges, because the constants are uncertain

Conversion factors come from primary sources — Mistral's peer-reviewed lifecycle assessment and published California almond water-footprint studies — and the interface reports a sourced range rather than one confident number, because the underlying science doesn't support one.

03

Guards, since the API costs money

IP-based rate limiting through Upstash Redis, server-side request validation, hard output token caps, and a pinned model version so two runs a month apart produce comparable estimates.

04

Tested where it matters

Unit tests cover the conversion logic — the part where a wrong constant produces a plausible-looking number nobody would catch by eye. The interface is responsive across desktop and mobile.

Why it exists

Same instinct as the thesis

My thesis found that the model with the best accuracy wasn't the one you'd deploy, because the headline number hid which errors it was making. Almond Jug comes from the same place. The honest version of "how much water does this use" is a range with citations, not a single figure — so that's what it shows, even though one confident number would look cleaner.
